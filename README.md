# 醒签

一张放在桌面角落的小卡片，用来收好最近几个月真正重要的话。应用使用 Electron，同一套界面可在 Windows 和 macOS 运行；内容保存在本机用户数据目录，不需要账号。

## 当前功能

- 默认在屏幕右上方显示，窗口可拖动。
- 支持始终置顶、登录时自动显示，以及系统托盘 / 菜单栏收起与唤回。
- 可添加提醒语和出处，并单独指定最高优先级；每句可设 3 个月、6 个月、1 年或长期保留。
- 每天打开时可轮换提醒语，也可以手动换一句。
- 折叠后仍在右上角显示优先级最高的提醒长条，点击长条可展开卡片。
- 管理页面可编辑或删除内容。数据保存在本机的应用数据目录。
- Windows 安装版支持后台检查、下载更新，并在退出应用时安装。

## 本机预览

需安装 Node.js。进入本目录后运行：

```bash
npm install
npm start
```

`npm start` 会打开桌面预览；登录启动选项会在打包安装后生效。

## 打包

```bash
npm run dist:win
npm run dist:mac
```

打包建议在对应系统上分别进行。macOS 登录启动项要稳定生效，发布版还需要代码签名并完成 Apple 公证；首次启动时也请在系统的“登录项”设置中确认醒签已启用。Windows 首次运行后可在“设置 → 应用 → 启动”中查看开关。

## Windows 自动更新发布

醒签使用 `Jacob118/xingqian` 的 GitHub Releases 检查和分发 Windows 更新。本地构建时设置仓库：

```powershell
$env:XINGQIAN_GITHUB_OWNER = "Jacob118"
$env:XINGQIAN_GITHUB_REPO = "xingqian"
npm run dist:win
```

把带有新版本号的提交推送到 `main` 后，GitHub Actions 会自动构建安装程序并发布公开 Release。Actions 使用仓库自带的短期令牌，不需要把令牌写进项目。每次发布前要先增加 `package.json` 和 `package-lock.json` 中的版本号。

`npm run dist:win` 只在 `release` 中本地生成安装程序和更新清单，不会上传。

安装包启动后会自动检查新版本，也可以在管理页手动检查。更新会在后台下载，并在从系统托盘退出醒签时安装。不要混用不同版本生成的清单和安装文件。

第一次启用自动更新时，需要发布并手动安装一次已接入 GitHub 仓库的新版本（当前版本为 0.2.0）；现有 0.1.0 没有更新器，无法自行发现它。之后向同一个仓库发布新版本，就不需要每次手动下载安装。当前没有 Authenticode 证书，因此会关闭 Windows 发布者证书校验；公开分发时建议配置代码签名证书。

## 说明

首次启动放入一条示例提醒语，用户可以删除或替换。Mac 版本仍需在 Mac 上打包；Windows 自动更新只有在构建时配置更新源并上传发布文件后才会启用。
